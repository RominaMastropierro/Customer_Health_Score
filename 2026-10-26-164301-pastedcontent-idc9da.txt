> quiero incorpora en mi aplicacion una funcionalidad que al escribir un valor
  en el campo CUIT del formulario de alta de un cliente la aplicacion consulte
  los datos de deudores del BCRA. Para esto el camino a seguir sera: la
  aplicacion front consulta a un endpoint de nuestra API pidiendo los datos de
  deudores para el CUIT ingresado. Nuestra API al recibir la peticion con el
  CUIT debe consultar la API publica del BCRA con la informacion que obtiene
  utiliza al archivocentral-deudores-v1.md y muestre un texto en pantalla. En
  el formulario existente para agregar un cliente, el usuario ingresa un
  CUIT/CUIL en el campo correspondiente.

  Cuando el campo pierde el foco (blur), se debe ejecutar el siguiente flujo:

  Normalizar el CUIT/CUIL eliminando guiones, espacios y otros separadores
  permitidos.

  Validar que tenga 11 dígitos y comprobar su dígito verificador mediante el
  algoritmo correspondiente.

  Si el valor es inválido, mostrar un mensaje claro de validación y no realizar
  ninguna consulta.

  Si es válido, enviar una solicitud al endpoint del backend encargado de
  consultar la situación crediticia.

  Mientras se realiza la consulta, mostrar un indicador de carga y evitar
  solicitudes duplicadas para el mismo valor.

  Cuando llegue la respuesta, mostrar un mensaje comprensible para el usuario.

  Si el usuario modifica el CUIT/CUIL después de una consulta, invalidar el
  resultado anterior y consultar nuevamente cuando corresponda.

  No realizar la consulta directamente desde el navegador a la API del BCRA. La
  comunicación con el BCRA debe pasar por nuestro backend.
